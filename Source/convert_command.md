# Conversion via Inkscape:

## Base command

```cmd
inkscape DATEINAME.svg --export-filename=DATEINAME.pdf
```

## Specific command 1 (Seite 4 und 1)

```cmd
inkscape Seite_4_und_1.svg --export-filename=Seite_4_und_1.pdf
```

## Specific command 2 (Seite 2 und 3)

```cmd
inkscape Seite_2_und_3.svg --export-filename=Seite_2_und_3.pdf
```
